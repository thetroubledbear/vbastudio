B2

Everything the VBE never gave you

Real breakpoints

Click the gutter in VS Code. Execution actually stops there, inside your live workbook — not a guess, a real pause.

Inspect locals

See every variable's current value the moment you're paused, in the Variables pane — no more Debug.Print archaeology.

One-click run

A sidebar tree of every module and procedure, plus a status-bar quick-jump — type a name, hit enter, it runs.

Text on disk

Your VBA source lives as real .bas/.cls files, under git, diffable and reviewable like any other code.

Two-way sync

Pull code from Excel to disk, edit in VS Code, push it back. If both sides changed since the last sync, vbastudio flags the conflict instead of silently overwriting — deletions sync too.

Excel stays Excel

No add-in to install inside Excel, no macro security to fight. vbastudio drives the workbook you already have open.
